02 · Usage

1行1ターンからステレオWAVへ

CUDA GPU環境で`uv sync`を実行後、同梱CLIから推論できます。モデルがprivateの間はHugging Faceへのログインが必要です。

Quick start
$ git clone https://github.com/llm-jp/zoom1-dialogue-tts.git
$ cd zoom1-dialogue-tts
$ uv sync
$ uv run hf auth login
$ uv venv --python 3.12 .venv-vap
$ uv pip install --python .venv-vap/bin/python --no-deps maai
$ uv pip install --python .venv-vap/bin/python torch torchaudio \
    numpy soundfile librosa einops rich matplotlib scipy \
    transformers==5.5.3 huggingface-hub pygame
$ uv run zoom1-dialogue-tts examples/dialogue.txt \
    --variant drop \
    --turn-timing vap-auto \
    --vap-python .venv-vap/bin/python \
    -o out/dialogue.wav
01

Script

`[S1]`と`[S2]`で始まる日本語対話を用意します。JSON/JSONLにも対応します。

02

Voices

参照音声を省略して生成音色を使うか、許諾済み音声を話者ごとに指定します。

03

Timing

`--turn-timing vap-auto`で生成からVAP SHIFT適用まで1コマンドです。未予測境界はZoom1統計へfallbackします。

03 · Pipeline

逐次生成と時間編集を分離

FireRedTTS-2は各ターンを文脈付きで生成し、後段で話者別チャンネルへ配置します。重なりはfull-duplex生成ではなく、再現可能な時間編集です。

InputDialogue script[S1] / [S2]
→
SynthesisFireRedTTS-2Zoom1 fine-tune
→
TimingVAP SHIFT + BCgap · overlap · backchannel
→
OutputStereo WAVL=S1 · R=S2

Current scope

VAPは短い相槌に加え、通常ターンのSHIFT/HOLDから間・食い込みを制御できます。FireRed生成、VAP解析、FTO適用は1コマンドで実行できます。
