## Model

Current default model:

llm-jp/zoom1-dialogue-tts

Default checkpoint:

drop

The "drop" checkpoint removes overlapping backchannels during generation.
Backchannels are expected to be inserted later by downstream timing models such as VAP or MaAI.

## GPU

Use CUDA whenever available.

Before inference:

```bash
nvidia-smi
```

If CUDA runs out of memory:

Do not modify the code first.

Instead:

- check GPU usage
- wait for memory
- ask before changing precision or CPU execution
